# 🚘 Despachante GSM

Landing page moderna, rápida e focada em conversão para um escritório de despachante documentalista veicular. Projeto desenhado para automatizar o primeiro atendimento, fazendo uma triagem do cliente e enviando os dados (serviço desejado e placa do veículo) diretamente para o WhatsApp da empresa.

## ✨ Funcionalidades

- **Triagem Inteligente:** Formulários que ajustam o serviço desejado e a placa do veículo antes do contato.
- **Integração Dinâmica com WhatsApp:** URL personalizada envia uma mensagem pré-formatada para o WhatsApp do escritório.
- **Design Responsivo (Mobile-First):** Layout adaptado para mobile, garantindo leitura perfeita, botões acessíveis e menus otimizados para o toque.
- **Sistema de Modais:** Catálogo de serviços detalhado operando via modais, permitindo solicitação rápida de orçamento sem sair da página.
- **Slider Automático:** Carrossel de banners na página inicial promovendo os principais serviços e diferenciais.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído sem o uso de frameworks pesados, pra garantir o carregamento instantâneo da página:

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização com variáveis globais, Flexbox, CSS Grid e Media Queries para responsividade.
- **JavaScript (Vanilla):** Lógica de modais, formatação de inputs, controle do slider e montagem dinâmica de links do WhatsApp.
- **FontAwesome:** Biblioteca de ícones.
